# Banner 4 food-grain sketch underlay

Source: user-supplied `C:/Users/ejiog/Downloads/nuts.jpg`.

One built-in Imagegen style-transfer request retained the portrait arrangement of bowls of grains, seeds, pulses, and oats with the spoon. The native 1024×1536 RGB output is preserved unchanged. Its gray checkerboard is baked into the raster; the PNG itself has no alpha.

As with banner 3, native CSS `grayscale(1) brightness(1.5) contrast(1.5)` lifts the light background tones to white. Multiply blending makes those areas disappear into the banner. Transparency is applied in the site presentation rather than stored in the source PNG.

The sketch is decorative, ignores pointer input, and takes no layout space. It appears only on banner 4. The denser food contours use 14% desktop / 10% mobile opacity, with the same edge fades as the other underlays. Existing copy, foreground food artwork and animation remain intact.
